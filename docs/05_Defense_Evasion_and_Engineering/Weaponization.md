# ⚔️ Payload Weaponization

Static signatures are dead. If you drop a raw .exe or unencrypted shellcode on a modern system, EDRs (Endpoint Detection and Response) will flag it instantly.

Advanced Persistent Threats run entirely in memory. To achieve this, your payload must be encrypted on disk and only decrypted inside the RAM of a hijacked process.

## 🍯 zencefil-weaponizer.py

This tool takes your raw shellcode (e.g., generated by Metasploit or Cobalt Strike), encrypts it using AES-256 CBC, and encodes it into Base64.

### Usage

You can find the script in the tools directory.

```bash
pip install cryptography
python3 zencefil-weaponizer.py -i payload.bin -o obfuscated_payload.txt
```
